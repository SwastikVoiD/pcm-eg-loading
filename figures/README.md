# Figures

Generated by the Python mirror (`python/figures.py`) from the same cases as the MATLAB results; the
underlying numbers agree with MATLAB to round-off. `matlab/scripts/make_figures.m` produces the
MATLAB versions.

| File | Content |
| --- | --- |
| `fig1_k_models.png` | Conductivity gain against EG loading: the three route slopes, Maxwell's model and the published data |
| `fig2_validation.png` | Model against the Neumann solution at 30 and 120 min |
| `fig3_transient_example.png` | HTF temperature, melt fraction and stored energy for constant, sine and square sources (erythritol, 5 wt% EG, low route, P = 60 min, A = 20 K) |
| `fig4_E_vs_w.png` | Stored energy against EG loading, erythritol low route, 30 and 60 min windows with P = t_c |
| `fig5_optimum_map.png` | Optimum loading against charging window per PCM and route; error bars span every fluctuating source |
| `fig6_penalty_vs_ratio.png` | Design penalty and change in achievable energy against P/t_c for every fluctuating case |
| `fig7_bypass.png` | Bypass rule against HTF always flowing, 60 min window |
| `fig8_convection_bound.png` | Conduction-only and convection-bound curves, erythritol low route |

In Figs 5 and 6, points with P > t_c use four start phases; converged 16-phase values are in
[docs/FINDINGS.md](../docs/FINDINGS.md).
